# GizTech Engineering Thinking Frameworks

A structured, open-source educational project designed to teach the core mental models of modern engineering: requirements, system decomposition, pseudocode, flowcharts, trade-off analysis, iteration and technical communication.

This repository supports my **GizTech Engineering Thinking Series** on my channel and culminates in a live online **GizTech Engineering Thinking Masterclass** where mentees apply these frameworks and submit open-source contributions.
