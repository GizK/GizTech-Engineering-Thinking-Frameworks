# [Pseudocode & Flowcharts](ca://s?q=Teach_pseudocode_solution_choice)
This folder contains two tasks: writing pseudocode for engineering decisions and creating flowcharts for system decomposition.

---

## Task 1 — Pseudocode for Choosing Between Two Solutions
Write pseudocode that compares two engineering options.

### Guidelines
- Use clear decision logic.
- Show the criteria used to choose.
- Keep it readable and structured.

### Submit as:
`pseudocode-solution-choice-<your-name>.md`

---

## Task 2 — Flowchart for System Decomposition
Create a flowchart that maps the decomposition of a system.

### Guidelines
- You draw the flowchart and upload an image OR describe it in text.
- Show the sequence and decision points clearly.

### Submit as:
`flowchart-system-decomposition-<your-name>.md`
