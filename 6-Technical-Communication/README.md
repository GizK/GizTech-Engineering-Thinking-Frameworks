# [Technical Communication](ca://s?q=Teach_docstring_template)
This folder teaches how to write clear, professional docstrings.

## What you will do
Create a high-quality docstring template for a sample function.

## Your task
Write a docstring that includes:
- A clear description  
- Parameters  
- Returns  
- Example usage  

## Guidelines
- Use concise, professional language.
- Follow a consistent structure.
- Make it understandable to beginners.

## How to submit
Add a file named:
`docstring-template-<your-name>.md`
