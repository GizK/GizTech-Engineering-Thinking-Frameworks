# [Iteration Frameworks](ca://s?q=Teach_iteration_login_system)
This folder focuses on iterative improvement.

## What you will do
Document **three iterations** of improving a login system.

## Your task
Describe the following iterations:
1. Basic login (username + password)
2. Password strength + lockout rules
3. Two-factor authentication

## Guidelines
For each iteration, explain:
- What changed  
- Why it improved the system  
- Any trade-offs introduced  

## How to submit
Add a file named:
`login-system-iterations-<your-name>.md`
