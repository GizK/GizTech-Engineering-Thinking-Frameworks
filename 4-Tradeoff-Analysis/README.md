# [Trade-Off Analysis](ca://s?q=Teach_tradeoff_analysis)
This folder teaches how to compare engineering options using structured trade-off reasoning.

## What you will do
Choose ONE of the following:
1. Compare two ML models  
2. Compare two system designs  

## Your task
Create a trade-off matrix comparing the two options using criteria such as:
- Accuracy  
- Performance  
- Scalability  
- Interpretability  
- Cost  
- Complexity
Write a conlcusion.
Use trade off matrix

## Guidelines
- Use a table for the comparison.
- Write an explanation justifying your decision.
- Be objective and structured.

## How to submit
Add one of:
- `tradeoff-ml-models-<your-name>.md`
- `tradeoff-system-designs-<your-name>.md`
