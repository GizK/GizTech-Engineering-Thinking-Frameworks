# [System Decomposition](ca://s?q=Explain_data_pipeline_components)

This folder focuses on breaking a system (specifically a **data pipeline**) into clear, logical components.

## What you will do
Decompose a data pipeline into its major stages and explain the purpose of each.

## Your task
Break the pipeline into components such as:
- Ingestion  
- Cleaning  
- Transformation  
- Storage  
- Reporting  

## Guidelines
- Explain each stage in a paragraph or bullet-points.
- Show how data flows through the pipeline.

## How to submit
Add a new file named:
`data-pipeline-decomposition-<your-name>.md`
