# [Problem Definition](ca://s?q=Explain_functional_nonfunctional_requirements)

This folder teaches how to define engineering problems using **functional** and **non‑functional** requirements (the foundation of structured engineering thinking)

## What you will do
Create a short requirements document for a simple system of your choice (for example a login system, dashboard, monitoring tool etc.)

## Your task
Write:
- 3 functional requirements (what the system must do)
- 3 non‑functional requirements (how well it must perform)

## Guidelines
- Use clear language.
- Keep explanations concise but precise.
- Follow the examples from the GizTech Engineering Thinking Series.

## How to submit
Add a new file named:
`<system-name>-requirements-<your-name>.md`
