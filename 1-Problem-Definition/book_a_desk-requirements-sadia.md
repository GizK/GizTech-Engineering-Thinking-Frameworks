Book a desk system
A system for office hotdesking where workers can book desks before going into the office

Functional Requirements:
- Allow users to log in using username and password specific to them
- Layout the office and the seats in an interface
- Block out rooms and desks that are being used

Non-functional requirements
- The site should be up to date to prevent clashes
- The site should be available all day
- The site should have multiple users use it without crashing
- Should be simple and easy to use
