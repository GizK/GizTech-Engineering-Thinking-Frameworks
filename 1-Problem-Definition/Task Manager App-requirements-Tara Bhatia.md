Functional Requirements
1. User Authentication-The system shall allow users to create an account, log in securely, and log out.
2. Task Management-The system shall enable users to add new tasks, view a list of existing tasks, mark tasks as complete, and delete tasks.
3. Task Organisation-The system shall let users set a due date for each task and sort tasks by date or completion status.

Non-Functional Requirements
1. Usability-The system shall be intuitive enough that a new user can add their first task within 30 seconds without assistance. 
2. Performance-The system shall load the task list within 2 seconds on a standard internet connection.
3. Reliability-The system shall store task data securely and retain all task information when the app is closed and reopened.
